# 🕵️‍♂️ tg_user_tracker
***a simple Python script for tracking the online status and new messages of a specific user***

# functional
* online status tracking
* shows new messages from a specific user

# configuration

Create a file named `"secret.py"` in the same folder as `"main.py"` and populate it as follows:

```python
api_id = "your api_id"
api_hash = "your api_hash"
phone = "your phone"
```

> **How to get API credentials:**
> 1. Go to [my.telegram.org](https://telegram.org) and log in with your phone number.
> 2. Navigate to **API development tools**.
> 3. Create a new application to get your `api_id` and `api_hash`.
